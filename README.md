# 欧洲油画工坊 · Atelier

一个零依赖的单文件网页应用：在浏览器里学欧洲油画、用油画笔触作画、上传名画自动拆解成可临摹的作画步骤。

**在互联网上，成为你自己的达·芬奇。**

## 使用

无需安装任何东西，直接用浏览器打开 `index.html` 即可（推荐 Chrome / Edge）。

## 功能

### 🎨 画室
- 六种模拟真实油画工具的笔刷：圆头笔、平头笔、扇形笔、画刀厚涂、罩染薄涂、调和笔（数字版达·芬奇晕涂法 sfumato）
- 18 色大师调色盘（那不勒斯黄、深茜红、凡·戴克棕、普鲁士蓝……），支持自定义调色
- 一键铺古典有色底、撤销、保存 PNG
- 画布缩放（25%–400%）：Ctrl+滚轮以鼠标为中心缩放，空格+拖动平移，方便放大画细节

### 🖼 拆解临摹
上传任意一张油画（全程浏览器本地处理，不上传网络），自动拆解为对照古典「七步作画法」的步骤图：

1. 有色底（含建议底色与对应大师颜料）
2. 起形线稿（边缘检测 + 九宫格定位辅助线）
3. 单色底层画（熟褐色五调子）
4. 铺大色块（模糊 + 颜色量化，算法替你"眯眼"）
5. 塑造层次
6. 高光点位
7. 完成对照

并从画中聚类提取 8 色「画中调色盘」（映射到最接近的大师颜料名，可一键设为画笔颜色）。任意步骤图可半透明垫入画室临摹（可调透明度），也可下载。

### 📜 学堂
写给零基础小白的完整教程：装备清单与省钱方案、古典七步作画法、技法百科（蛋彩画/坦培拉、古典多层罩染、sfumato、直接画法 Alla Prima、厚涂 Impasto 等）、调色入门、以及按月推进的「达·芬奇之路」学习路线。

## 技术

纯 HTML + CSS + 原生 JavaScript，无任何构建工具与外部依赖。笔刷引擎基于 Canvas 2D（逐笔毛描绘、颜料耗尽模拟、像素级揉合），拆解引擎基于 Sobel 边缘检测与 k-means 颜色聚类。
